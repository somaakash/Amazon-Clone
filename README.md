# 🌐 Amazon Clone –  Project

This is a simple Amazon Homepage Clone built using **pure HTML and CSS**.  
The project focuses on practicing responsive layouts, navbar creation, flexbox, grid, and basic UI styling.

This webpage is a beginner-friendly project created while learning from **Apna College**.  

--------------

## 🚀 Features

- 🔍 Responsive Amazon-style navigation bar  
- 🛒 Cart, account & address sections  
- 🟨 Fully functional search bar UI  
- 🖼 Hero banner section  
- 🧩 Multiple shopping category boxes  
- 📦 Footer with multi-column links  
- 💡 Clean and readable HTML + CSS code  
- 💻 No frameworks used — built from scratch  

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3 (Flexbox, Grid)**  
- **Font Awesome Icons**

---

## 🎯 What I Learned

- How to structure a webpage using HTML  
- Creating reusable components (navbar, cards, footer)  
- Using **Flexbox** for alignment  
- Using **CSS Grid** for multi-column layouts  
- Applying hover effects and transitions  
- Building pixel-perfect UI by observing the Amazon website
